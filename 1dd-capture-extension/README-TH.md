# 1DD Capture

ส่วนขยาย Chrome สำหรับส่งภาพแท็บที่เปิดและล็อกอินไว้แล้วเข้า 1DD Guide

เปิด `chrome://extensions` → Developer mode → Load unpacked → เลือกโฟลเดอร์นี้
ใน Guide เปิดเมนู Workspace (ล่างซ้าย) → ส่วนขยายจับภาพ คัดลอก URL และรหัสเชื่อมต่อมากรอกในส่วนขยาย
เปิดหน้าแก้ไขเนื้อหาปลายทางค้างไว้ ส่วนขยายจะหาแท็บ Guide จากโดเมน (v1.1.0 ใช้ได้ทั้งเว็บใหม่และเว็บเดิม)
จากนั้นเปิดแท็บหลังบ้านลูกค้าและกด “จับภาพส่งเข้า 1DD” แล้วกลับมาตรวจและยืนยันภาพใน Guide

จับเฉพาะบริเวณที่มองเห็นในแท็บ ไม่อ่านรหัสผ่านหรือ cookies ต้องเปิด Guide ไว้ในเบราว์เซอร์เดียวกัน
โลโก้ 1DD และ Google Sans ไทย/อังกฤษบรรจุไว้ในส่วนขยาย ไม่โหลดจากบริการภายนอก
